# GitHub Setup Commands

## After creating repository on GitHub:

1. **Add GitHub remote:**
```bash
git remote add origin https://github.com/YOUR_USERNAME/event-nexus.git
```

2. **Push to GitHub:**
```bash
git push -u origin main
```

3. **Verify push:**
```bash
git remote -v
git status
```

## Replace YOUR_USERNAME with your actual GitHub username

Example:
```bash
git remote add origin https://github.com/samarthchoudhary/event-nexus.git
git push -u origin main
```
